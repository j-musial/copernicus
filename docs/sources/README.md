# Source extension documentation

This directory contains the harvested specification descriptions of the 31 STAC extensions
that were merged into the Copernicus STAC Extension. Each file is named after the extension
and the exact upstream version it was harvested from.

**Note:** Field names in these documents have been rewritten to their `copernicus:`
equivalents. See the [field mapping table](../../README.md#field-mapping) in the main
README for the original-to-copernicus name mapping.
